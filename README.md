# Validade Inteligente

## Sobre o Projeto

O Validade Inteligente é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), com a proposta de auxiliar na organização e no gerenciamento de alimentos, contribuindo para o controle dos produtos e a redução do desperdício.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Checklist do Projeto

O checklist acompanha os requisitos estabelecidos no planejamento do TCC.

- [ ] Projeto publicado no GitHub Pages, Vercel ou Netlify.
- [ ] Layout responsivo, sem rolagem horizontal.
- [ ] Manipulação do DOM com uso de `preventDefault()`.
- [ ] Dados persistidos com `localStorage`, mantendo as informações após atualizar a página (F5).
- [ ] Console do navegador sem erros vermelhos.
- [ ] Testes realizados com pelo menos 5 usuários reais.
- [ ] Matriz de Feedback elaborada.
- [ ] Pelo menos uma melhoria visual ou funcional aplicada a partir dos feedbacks.
- [ ] Trabalho escrito com citações exclusivamente indiretas no formato (Autor, ano).
- [ ] Apresentação preparada com 5 slides.
- [ ] Pitch de 5 minutos ensaiado.
